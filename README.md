# AI Spend Audit

AI-powered audit tool for startups to optimize spending on AI subscriptions and infrastructure tools.

## Live Demo

https://ai-spend-audit-black.vercel.app

---

## Features

- AI spend audit dashboard
- Dynamic savings calculations
- Tool-specific optimization logic
- AI-generated summary section
- Lead capture form
- Shareable audit IDs
- High savings consultation CTA
- localStorage persistence
- Responsive SaaS-style UI
