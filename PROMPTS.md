# AI Prompts

## Personalized Audit Summary Prompt

Generate a concise AI spend optimization summary for a startup team.

Inputs:
- AI tool name
- monthly spend
- team size
- savings estimate
- recommendation

Output requirements:
- Around 100 words
- Professional tone
- Mention savings opportunities
- Mention productivity impact
- Encourage optimization

---

## Reasoning

The prompt was designed to:
- produce concise summaries
- avoid hallucinations
- focus on actionable recommendations
- sound like a professional SaaS audit report

---

## Fallback Strategy

If AI generation fails:
- use a predefined template summary
- still display savings insights to user

---

## AI Usage

AI was only used for:
- personalized summary generation

Core audit calculations use hardcoded business logic for reliability and transparency.
